# EcoPralnia: prompty do Gemini, partia 2 (16 obrazów)

Jak generować (tak jak poprzednio):
- Każdy prompt osobno, proporcje z nagłówka. Wybierz najlepszą z 2–3 wersji.
- Odrzuć obraz z tekstem, logo, metką z literami, ludźmi, dłońmi lub częścią ciała, manekinem z twarzą, zdeformowaną tkaniną.
- Zapisz pod nazwą z nagłówka i wrzuć do czatu (możesz partiami). Przycięcie i kompresję robię ja.
- Wszystkie obrazy pokazują ubrania i materiały, nie pralnię EcoPralnia ani jej pracę. Nie generujemy wnętrza pralni, domu, szyldu ani ludzi.

Wspólny styl (jest już w każdym prompcie): spokojna fotografia produktowa, miękkie dzienne światło, paleta granat, kość słoniowa, kamienny beż.

Mapa strony (gdzie trafi każdy obraz):

| Miejsce | Obrazy |
|---|---|
| Hero, tło całej szerokości | `hero-wide` |
| Metoda, tło + 3 karty | `bg-water`, `m-colors`, `m-fresh` (+ masz już `fabric-cashmere`) |
| Co przyjmujemy, 9 kafli | `tile-coat`, `tile-down`, `tile-shirt`, `tile-curtains`, `tile-leather`, `tile-rug` (+ masz już `hero-wool`, `tulle-pearls`, `fabric-linen`) |
| Tryby prania, 3 kadry | `mode-standard`, `mode-24h`, `mode-sameday` |
| Suknie ślubne, tło + kolaż | `bg-tulle`, `dress-hanger`, `dress-lace` |
| Opinie, Kontakt | masz już `bg-linen`, `bg-navy-wool` |
